Tabbycat Exporter

Export breaking teams and speaker standings to CSV for Google Slides generation.

API Credentials

Leave empty to export the open division (all speakers). Select a category like "Union Cup" for filtered standings.

Sequence number of the last round to include. Leave blank for current standings.

Tie rule: Includes all speakers ranked 10th or better. If ties push the list beyond 10 speakers, that's fine. Anyone ranked 11th or worse is excluded. Rank numbers use ordinal formatting (1st, 2nd, 3rd).

API Endpoints

  • POST /test-connection — Test break API, list break categories
  • POST /export — Form break CSV download
  • POST /api/export — JSON break export
  • POST /api/export-csv — Raw break CSV text
  • POST /test-speaker-connection — Test speaker API, list speaker categories
  • POST /export-speakers — Form speaker CSV download
  • POST /api/export-speakers — JSON speaker export
  • POST /api/export-speakers-csv — Raw speaker CSV text
  • POST /api/debug — Debug break responses
  • POST /api/debug-speakers — Debug speaker responses
