🔗 API Endpoints (for Apps Script / automation)

POST /api/export — Returns JSON with csv field

POST /api/export-csv — Returns raw CSV text

Both accept the same JSON body:

{
  "base_url": "https://ndc2025.calicotab.com",
  "token": "your_api_token",
  "slug": "ndc2025",
  "category_slug": "open",
  "debate_format": "bp",      // "bp", "3v3" (AP / Australs / UADC) or "wsdc"
  "intro_rows": true,
  "export_type": "break",     // "break" (default) or "awards"
  "award_tab": "open",        // awards only: "open", a speaker category slug, or "replies"
  "top_n": 10,                // awards only
  "suffix_break": "OPEN BREAKING TEAM",   // optional text added inside the cells (all four optional):
  "suffix_points": "Team Points",         //   points / wins
  "suffix_score": "Speaker Points",       //   total speaker score / average total speaker score
  "suffix_rank": "BEST EFL SPEAKER",      //   awards: the rank ("2ND BEST EFL SPEAKER")
  "suffix_average": "average speaks",     //   awards: the average
  "ordinal_case": "upper"                 // "upper" (1ST) or "lower" (1st)
}

intro_rows is optional (default true); send false for one row each. For "export_type": "awards" the columns are rank, speaker, team, average and category_slug is not needed. In the break file the Break column holds the break rank, or the remark (Capped, Ineligible, Reserve, Withdrawn) of a team that is not breaking.
